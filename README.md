# Peddlers 30A — 6 Hero Section Showcase

This interactive showcase viewer organizes all **6 hero section versions** into a presentation carousel with bottom navigation arrows, quick-jump pagination, responsive device simulation, and keyboard navigation.

---

## 🚀 Quick Start

You can view the showcase in two ways:

1. **Direct Double-Click**:
   - Double-click [`index.html`](./index.html) to open the interactive viewer directly in Google Chrome, Microsoft Edge, or any modern browser.

2. **Local Preview Server** (Recommended):
   - Double-click [`preview.bat`](./preview.bat) to launch Python's built-in local server at `http://localhost:8000`.

---

## 🕹️ Controls & Navigation

- **Bottom Navigation Dock**:
  - **Left Arrow (`←`)**: Move back to the previous hero section.
  - **Center Display**: Shows current hero number, design style, title, and descriptive summary.
  - **Right Arrow (`→`)**: Move forward to the next hero section.
  - **Numbered Dots (`1` – `6`)**: Click any dot to jump straight to that hero version.
  - **Jump Menu**: Dropdown to select any hero version with full title and description.
  - **Autoplay (Play/Pause)**: Automatically advances through the hero sections every 7 seconds.

- **Screen Edge Paddles**:
  - Subtle floating arrows on the left and right edges of the screen for quick one-click navigation.

- **Keyboard Shortcuts**:
  - `←` (Left Arrow) or `A`: Previous hero version
  - `→` (Right Arrow) or `D`: Next hero version
  - `1` through `6`: Jump directly to versions 1 to 6
  - `Spacebar`: Toggle slideshow autoplay
  - `H`: Hide/Show control panels for a completely clean view
  - `F`: Toggle Fullscreen mode

- **Top Bar Tools**:
  - **Device Viewport Switcher**: Switch between **Full (100%)**, **Laptop (1400px)**, **Tablet (1024px)**, and **Mobile (420px)** previews.
  - **Standalone**: Opens the active hero section directly in a standalone browser tab.
  - **Hide UI / Fullscreen**: For presentation and client review.
